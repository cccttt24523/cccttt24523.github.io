走进体验馆：智慧养老如何落到一床一椅

作者：张才腾

实地调研报告

调研地点：广东佛山顺德北滘镇广东工业设计城 · 永爱智慧养老新生活体验馆

调研对象：广东永爱医养产业有限公司（永爱医养）

调研方式：实地参观观察 + 公开资料研读 + 行业政策与统计文献比对

摘要

本次实地调研走访佛山永爱智慧养老体验馆，核心命题：智慧养老的难点不在技术，而在用得起、用得懂。体验馆不是单品展厅，而是一套可复制的照护场景样板间，把能力评估、居家适老改造、智能监测、平台运营形成业务闭环。永爱医养的竞争壁垒来自场景化整体解决方案加上国家级目录资质背书，而非单一硬件产品。当前行业核心矛盾不是硬件性能不足，而是设备误报干扰、老年人使用门槛、支付结构错位；B/G端项目模式已经跑通，居家C端家庭市场仍然面临转化难题。报告结合现场观察、SWOT分析，提出产品设计机会与体验馆优化建议。

一、调研问题与先行结论

1.1 核心调研问题

  1. 体验馆使用哪些产品与场景回应老年人真实照护需求？
  2. 企业如何从“卖适老家具”转型为“卖场景化解决方案”，商业模式发生怎样变化？
  3. 智慧养老发展真正卡点，是技术供给，还是支付能力与老年人使用门槛？

1.2 先行结论

  • 体验馆本质是可复制场景样板间，打通评估‑照护‑监测完整闭环，不是简单的产品陈列。
  • 永爱医养核心竞争壁垒是场景化整体方案+国家级推广目录背书，单品硬件本身并不稀缺。
  • 适老化落地最大落差来源于设备误报、老人使用习惯、支付结构，并非硬件性能短板。

二、行业背景：银发浪潮与智慧养老赛道

2.1 人口老龄化现状

根据《2025年度国家老龄事业发展公报》，截至2025年末，全国60周岁以上人口32338万人，占总人口23.0%；65周岁以上22365万人，占15.9%，我国进入中度老龄化社会，大约每4人中就有一位老年人。老年人口抚养比达到23.1%，人均预期寿命79.25岁，高龄、失能带来居家照护刚性需求。

2.2 市场规模与政策环境

智慧养老市场持续扩张，2024年市场规模约6.80万亿元，2025年预测7.21万亿元，2021‑2024复合增长率12.34%。国家连续出台银发经济、养老服务改革相关文件，持续发布《智慧健康养老产品及服务推广目录》，目录成为政府、机构招投标重要资质通行证。

2.3 供给与供需缺口

养老赛道市场参与者快速增加，但供给仍存在结构性缺口：全国养老床位总量767.9万张，面对超3.2亿老年人口依旧紧张；家庭养老床位、居家适老化改造基数仍然偏低；长期护理保险待遇覆盖人数有限，决定了“用得起”的现实边界。

2.4 调研企业概况

广东永爱医养产业有限公司成立2012‑09，注册资本3000万元，总部位于佛山顺德工业设计城，国家高新技术企业，佛山唯一入选2024版三部委智慧健康养老推广目录企业。企业早期以适老家具为主，2019年转型智慧养老，整合16大产品线7000余款产品；商业模式由销售单品转向输出“智慧平台+智能硬件+持续运营”家庭养老床位整体场景方案。工商年报显示企业规模较小，与对外宣传服务规模存在口径差异，报告中区分工商登记口径与企业宣传口径。

三、现场主要发现：体验馆六个观察维度

3.1 空间动线：按老人生活流线布展，而非按产品品类陈列

体验馆参观流线顺序：评估小屋（认知、自理能力评估）→居家样板间（客厅卧室厨卫）→辅具体验区→智慧平台演示区。把抽象的解决方案转化为可体验的生活场景；展厅偏向演示展示，缺少真实老人长期生活痕迹，演示感大于日常真实感。

3.2 评估区：能力评估作为整套照护数据起点

设置评估小屋，开展老人自理、认知能力测评；规划AI智能评估室，用影像数据量化老人能力等级。评估结果直接决定护理等级、硬件设备布点位置、报警阈值，链路为：能力量化→护理等级→设备布点→预警阈值。传统人工评估耗人力时间，AI评估有降本潜力。

3.3 居家样板间：多类感知硬件集成部署

样板间在客厅、卧室、厨房、浴室部署十余种感知设备，统一接入智慧养老平台，形成感知‑报警‑响应链路。

空间主要部署设备
客厅智能摄像头、视频通话屏、烟感、紧急呼叫器、智能网关
卧室火柴人隐私摄像头、毫米波雷达、智能床带（心率呼吸睡眠监测）
厨房燃气报警自动关闸、冰箱门磁传感器
浴室漏水保护、防滑设施、紧急呼叫装置

3.4 适老家具：安全藏在细节人体工学设计

家具单品壁垒不高，但家具与传感器、呼叫器一体化集成是差异化点。核心设计点：圆弧防撞边角防磕碰；大拉手低阻力抽屉适配手部力量衰退；感应夜灯适配夜间起夜；预留助行器挂钩、充电插座、紧急呼叫预埋位，聚焦起身借力、防磕碰、夜间起夜、易操作四大刚需。

3.5 智慧养老平台：整套方案的中枢大脑

平台面向政府、机构客户，统一接入全部智能硬件。完整闭环链路：设备感知（跌倒、睡眠、呼救）→数据沉淀评估分级→社区/机构中枢响应处置→数据回流迭代优化。硬件只是感知触角，平台带来持续运营、复购能力，是区别普通硬件厂商的核心。重点解决独居空巢老人无人看护风险，把经验照护升级为数据驱动照护。

3.6 监测、报警迭代与运营、客群特征

睡眠体征监测采用毫米波雷达、智能床带非接触采集，无需穿戴；最大痛点是误报，翻身、宠物活动都会触发告警，需要在灵敏度和打扰之间权衡。产品持续迭代报警逻辑，例如起夜半小时未返回才触发报警，降低无效打扰；采用毫米波雷达+火柴人摄像头兼顾安全与隐私。

体验馆主要服务B端机构、G端民政政府项目；C端普通家庭客户转化难度高，障碍集中在价格、安装门槛、信任问题。企业获客依靠国家级资质、招投标、线上商城、官媒品牌背书。同时体验馆承担高校产教融合实训功能，提前储备养老行业人才。

四、核心分析过程

4.1 三大养老场景采购逻辑对比

维度 机构养老（招标驱动） 社区养老（政府主导普惠） 居家养老（子女情感决策）
核心诉求 规模化、耐用、合规 就近、普惠、可负担 安全、隐私、简单易操作
付费方 机构运营预算 政府补贴采购 家庭子女自费为主
决策者 招标采购方 民政街道部门 子女家属
体验馆表现 落地效果强 中等 演示强，实际转化弱

4.2 企业竞争力归因

不构成壁垒：普通适老家具、通用传感器，市场供应商充足，单品容易被比价替代。

真正核心壁垒三点：①场景化整合能力，把家具、硬件、平台、运维打包成完整可验收交付方案；②国家级推广目录资质，招投标市场准入优势；③顺德工业设计城产业生态，快速打样迭代。

4.3 三大核心问题归因

归因一：误报问题，技术理想与现实生活落差。监测设备很难做到零误报，阈值调灵敏就扰民，调保守会漏报。高频误报会导致老人主动关闭设备，设备彻底失效；产品能力不只看硬件参数，更要看告警阈值调优与真实用户留存。

归因二：支付链条话语权错位：买单者≠使用者。B/G端由政府、机构采购，产品优先满足招投标指标；真正使用的老年人在支付链条末端话语权最弱，容易出现“标书指标漂亮，老人实际不好用”。家庭养老床位模式依靠政府补贴三方分担成本，是现阶段最可行落地路径。

归因三：业务结构高度依赖B/G项目，C端零售尚未跑通。企业大量订单来自招投标项目；工商年报营收、人员规模，与宣传的服务老人规模存在量级差距，居家普通家庭市场还未规模化。

4.4 SWOT分析

  • S优势：多年医养场景整合沉淀；国家级目录资质；顺德制造业生态支持快速迭代。
  • W劣势：C端零售品牌弱；误报、用户体验仍需打磨；企业实际体量小于对外宣传。
  • O机会：银发经济政策红利；长护险扩面带来支付增量；AI评估、远程问诊拓展新服务。
  • T威胁：互联网家电大厂跨界入局；行业同质化价格竞争；地方补贴项目节奏波动，订单不稳定。

五、调研结论与设计启发建议

5.1 核心判断结论

  1. 智慧养老瓶颈不在于硬件技术，而在于支付能力（用得起）与使用门槛（用得懂）。B/G端成立的壁垒不能直接照搬到C端家庭市场。
  2. 智慧养老正在从比拼产品功能，转向比拼用户信任与设备长期留存率。一次性硬件销售价值有限，持续运营服务价值更高。
  3. 家庭养老床位模式依靠公共补贴分担成本，是当前落地效率最高路径；未来胜负手在于把机构级复杂方案降维改造，实现普通家庭买得起、装得上、用得懂。
  4. 告警只是安全底线；基于连续体征数据做风险预判、慢病管理，是智慧养老对比传统适老化改造的增量价值。

5.2 产品设计机会点

第一，面向家庭做零学习成本交互：语音呼救、单键操作、大字界面，降低老年人操作负担；构建低打扰告警规则引擎，学习老人作息，减少误报。同时设计子女端远程安心界面，平衡老人隐私与家属知情需求。

第二，数据价值从被动报警升级到主动健康管理：睡眠、活动、体征连续数据用于风险前置预警；打通AI评估、远程问诊，构建监测‑评估‑干预‑复评健康闭环；将复杂数据转化为普通人可以看懂的界面。

5.3 体验馆与企业改进建议

  • 增加接近真实居住的体验区域，弥补“只有演示没有真实日常”的短板，尽量模拟真实居家长期使用状态。
  • 对外信息口径透明化，区分工商实测数据、已落地业务、企业宣传、规划中功能，降低信息核验难度。
  • 建立真实用户反馈回流机制，把误报率、设备留存率纳入产品迭代考核，让使用体验和硬件功能同等重要。

5.4 调研方法层面反思

本次调研证据分层：区分“现场亲眼所见、现场讲解内容、企业宣传材料、未来规划功能”，不同信息可信度不同。本次局限：没有独立入户回访老年人，缺少终端使用者一手访谈；后续调研应补充入户回访，进一步验证居家场景真实使用感受。智慧养老不是高科技炫技，更多是在细节、阈值、安全规则上做克制的减法。技术落地成败关键要看：谁付钱、谁决策、谁真正使用三方是否对齐。
